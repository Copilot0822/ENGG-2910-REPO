# J1939 privacy audit

The paid/licensed CSS Electronics J1939 database is not included or redistributed.
Users must supply their own licensed local copy.

Licensed-derived outputs remain private, including raw CAN frames, synchronized
measurements, ground truth, catalogs, inferred definitions and checkpoints.
Output-local ignore rules protect custom directories. Only aggregate results,
methodology, source code and deliberately invented synthetic datasets are
intended for public distribution.

Current tracked files and reachable history on main were checked for licensed
J1939 databases and substantial derived definition collections. None were found.
Unit tests validate private-output guards, sanitized public evaluation output
and database-independent invented fixtures.

Historical licensed objects were removed from reachable refs, but GitHub
server-side retained/cached objects may require GitHub Support cleanup before
the repository is made public. Keep the repository private until server-side
cleanup has been confirmed.
